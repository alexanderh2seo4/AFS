DATENSCHUTZ & QUELLEN

Nur das Nötige auf der Karte

Die öffentliche Website enthält keine Teilnehmerdaten. Anonymisierte Einträge werden nach Eingabe eines privaten Zugangscodes von einem lokalen Datendienst abgerufen.

Homeinterviews, Hostees und Gastfamilien werden in einem groben Bereich angezeigt. Entfernungen sind Schätzungen. Hopees erscheinen ausschließlich im Gastland, ohne Wohnadresse. Dein Wohnort wird lokal im Browser gespeichert.

Die Kartenkacheln stammen von OpenStreetMap. Dabei erhält der Kartenanbieter deine IP-Adresse und den angezeigten Kartenausschnitt. Es werden keine Namen, Hausadressen oder AFSer-Zugangscodes an den Kartenanbieter gesendet.
