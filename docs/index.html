DATENSCHUTZ & QUELLEN

Nur das Nötige auf der Karte

Die anonymisierten Kartendaten sind öffentlich auf GitHub gespeichert. Namen, Kontaktangaben, genaue Adressen und vollständige AFSer-Datensätze bleiben lokal und werden nicht veröffentlicht.

Homeinterviews, Hostees und Gastfamilien erscheinen als 1-km-Kreise mit zufällig versetztem Mittelpunkt auf Basis öffentlicher Ortskoordinaten. Die Kreisfläche ist kein bestätigter Wohnort. Entfernungen sind Schätzungen. Awayees erscheinen ausschließlich im Gastland, ohne Wohnadresse. Dein Wohnort wird lokal im Browser gespeichert.

Die Kartenkacheln stammen von OpenStreetMap. Dabei erhält der Kartenanbieter deine IP-Adresse und den angezeigten Kartenausschnitt. Es werden keine Namen, Hausadressen oder AFSer-Zugangscodes an den Kartenanbieter gesendet.

Datenquelle: AFSer.de. Karten: © OpenStreetMap-Mitwirkende. Ungefähre Ortskoordinaten: GeoNames (CC BY 4.0). Kartenbibliothek: Leaflet (BSD-2-Clause).

Zuletzt veröffentlichter Datenstand wird von GitHub geladen.
